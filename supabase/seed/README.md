# Sample data

While the app is being built there are four sample employees
(`Sample Raja`, `Sample Meena`, `Sample Suresh`, `Sample Anil`) with about five
weeks of attendance, one sample holiday, and a few gaps (Anil's last three days
are left blank on purpose, to show "needs attention").

- Add: `sample_data.sql` (does nothing if sample data already exists).
- Remove: `remove_sample_data.sql`.

Both are run in the Supabase SQL editor (or by the developer). The owner asked
to keep sample data until the app is completely developed.
